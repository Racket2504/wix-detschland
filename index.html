Methodik & Quellen

Der WIX ist ein konstruierter Index mit subjektiver Gewichtung - transparent dokumentiert.

Gewichtung der 12 Indikatoren

Indikator Gew. Turnus

Scoring-Formeln (0-100 je Indikator)

BIP: clamp(50 + YoY/3 x 50, 0, 100) Industrie: clamp(50 + YoY/5 x 50, 0, 100) Auftraege: clamp(50 + YoY/5 x 50, 0, 100) Exporte: clamp(50 + YoY/4 x 50, 0, 100) Handelsb.: clamp(50 + YoY/10 x 50, 0, 100) ALQ: clamp(100 - (r-3) x 17, 0, 100) Insolvenz: clamp(50 - YoY/30 x 50, 0, 100) Inflation: clamp(100 - |r-2| x 25, 0, 100) Einzelhdl: clamp(50 + YoY/4 x 50, 0, 100) Bau: clamp(50 + YoY/5 x 50, 0, 100) Produktiv: clamp(50 + YoY/2 x 50, 0, 100) Schulden: clamp(100 - (r-60) x 5, 0, 100) WIX = Summe (Score_i x Gewicht_i)

Datenquellen

  • Destatis - BIP, Industrie, Auftraege, Einzelhandel, Inflation, Bau
  • Bundesagentur fuer Arbeit - Arbeitslosenquote, Insolvenzen
  • Eurostat - Exporte, Handelsbilanz, Produktivitaet, Schuldenquote
